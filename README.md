# ⚔️ The Quest Log — The Procrastination Translator

> Turn your boring tasks into epic adventures (and dodge them heroically).

A single-file, zero-dependency web toy for bored developers. Paste in a dull work task and it rewrites it into dramatic fantasy-quest language — then rewards you for doing absolutely no real work.

### 🔗 Live site: https://harirmdhn.github.io/quest-log/

## ✨ Features

- **📜 Quest Forge** — rewrites a boring task into an epic quest (*"Vanquish the Dragon of 'Reply to the email'…"*).
- **🎴 Shareable Quest Card** — generates a downloadable PNG card of your quest, perfect for team chat.
- **🧙 Excuse Oracle** — one click summons a legendary excuse for the tasks you'd rather avoid.
- **👹 Boss Battle** — turn your most dreaded task into a boss with a health bar and attack it until it falls.
- **💰 Loot Drops** — satisfying emoji loot rains down whenever you forge a quest or land a hit.
- **🏆 Stats panel** — tracks XP Avoided, Quests Forged, Excuses Cast, and Bosses Slain.

## 🚀 Running it

No build step. It's one HTML file:

```
open index.html
```

Or just visit the live site above.

## 🛠️ Tech

Plain HTML, CSS, and vanilla JavaScript. The quest card is rendered with the Canvas API. That's it — no frameworks, no npm, no reason not to procrastinate.
